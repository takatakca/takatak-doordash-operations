# Merchant operations workflow

## Inventory

Privately enumerate all accessible businesses, stores and support cases across available date ranges. Read open and closed cases; closed status does not establish that the underlying issue is resolved. Link related cases without duplicating their messages.

## Disputes and quality

Separate actual payment disputes or error charges from operational quality concerns. For each dispute, record the evidence, amount, submission deadline, previous reply and written outcome privately. Request itemized fee explanations and applicable credits based on source documents. Do not invent amounts or accept settlements without the user's specific direction.

## Tablet and integration routing

Map each store to its current receiving protocol, menu and location. Identify legacy integrations and provisioning requirements. Request authorized usernames and secure invitation/password setup links. Coordinate changes so a replacement tablet is ready before removing a working route. Record test and written confirmation independently of the request.

## Financial reporting

Export original reports for each completed month and mark current-period reports as month-to-date. Reconcile payouts, deductions, marketing charges, device fees and actual disputes. Store original reports and a completed register privately; keep only blank schemas in this repository.

## Portability

Use the CSV templates for extraction into a private tracker. A dated ZIP or copied folder is a snapshot, not ongoing synchronization. This repository does not install a recurring agent or automatically connect private storage.
