# TAKATAK — DoorDash Operations Templates

Public workflows and empty templates for merchant support, order routing and financial reconciliation.

## Files

- `WORKFLOW.md`: generic inventory, dispute, tablet/integration and reporting process.
- `AGENTS.md`: instructions for agents continuing authorized work while keeping operational evidence private.
- `templates/cases.csv`: empty case-register schema.
- `templates/financial-statements.csv`: empty report/export schema.
- `templates/store-routing.csv`: empty routing and verification schema.

## Public repository, private evidence

Actual support cases, account/store identifiers, amounts, customer data, financial reports, correspondence and private storage links belong in access-controlled storage outside this repository. The templates intentionally contain no real operational records. `.gitignore` helps prevent accidental additions but does not replace review.

Copy the templates to private storage and fill them there. Preserve original evidence and distinguish requests from confirmed outcomes. No automatic synchronization, scheduled agent or live integration is configured by this repository.
